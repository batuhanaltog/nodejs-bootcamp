# Node.js Bootcamp - My First Projects

This repository contains my first projects and practices during my Node.js learning journey. I followed Jonas Schmedtmann's course.

## 📁 Project Contents

### File System Operations
- **Synchronous File Reading/Writing**: Using `fs.readFileSync()` and `fs.writeFileSync()`
- **Asynchronous File Operations**: Using `fs.readFile()` and `fs.writeFile()` with callback structure
- File reading chain operations (callback hell example)

### HTTP Server
- Creating a simple HTTP server
- Routing structure (/, /overview, /product, /api)
- JSON API endpoint
- 404 error page
- HTTP headers management

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/batuhanaltog/nodejs-bootcamp.git

# Navigate to project directory
cd nodejs-bootcamp

# Start the server
node index.js
```

After starting the server:
- **Home Page**: http://localhost:8000/
- **Product Page**: http://localhost:8000/product
- **API Endpoint**: http://localhost:8000/api
